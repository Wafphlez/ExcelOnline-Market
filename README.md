# Excel Online Market

Веб-версия: [https://wafphlez.github.io/ExcelOnline-Market/](https://wafphlez.github.io/ExcelOnline-Market/).

Таблица рынка EVE Online: выгрузка ESI или свой Excel, маржа с вашими комиссиями, фильтры, сравнение двух регионов. Вкладка **Персонаж** — кошелёк, сделки и ордера через EVE SSO.

Excel разбирается в браузере. Наружу уходят выгрузка ESI, вход SSO и ссылки на EVE Tycoon. Книги остаются в этом браузере; файл с тем же именем заменяет предыдущий.

## Руководство

Вкладки: **Торговля** и **Персонаж**.

### Выгрузка

**Новая выгрузка ESI**

1. Регион: The Forge (Jita), Domain (Amarr), Heimatar (Rens), Sinq Laison (Dodixie), Metropolis (Hek).
2. История: **30**, **7** или **2** дня.
3. По желанию: **«Выгрузить актуальные ордера»**, **«Выгрузить только торговый хаб»**.
4. **«Сформировать (ESI)»**. Обычно несколько минут. **«Стоп → xlsx»** сохраняет уже собранное, **«Стоп → принудительно»** выходит без файла.

**Локальный Excel** — перетащите `.xlsx` / `.xls` или выберите файл.

### Регион

- **В одном регионе** — файл из списка и **«Открыть»**.
- **Между регионами** — регион 1, откуда везёте, регион 2, куда продаёте. **«Применить сравнение»**. Покупка — sell региона 1, продажа — sell региона 2. Сделки, оборот и средняя цена — с региона 2.

**Настройки → Основные → Выгрузки → Удалить выгрузки** стирает весь список.

### Таблица

Сортировка по колонке, фильтр под заголовком.

| Колонка | Смысл |
|---|---|
| Название | Клик копирует имя. Иконка открывает EVE Tycoon. |
| Объём перевозки | м³ за штуку; у кораблей packaged volume. |
| Маржа | После broker fee и sales tax. |
| Средняя в спреде | 0 % у buy, 100 % у sell. |
| Спред | sell − buy, ISK за штуку. |
| Выгодность входа | 0–100 %: маржа, ликвидность, спред. Выше порога цены вклад маржи слабее. |

**Применить все** включает базовый набор: сделки ≥ 20, маржа ≥ 5 %, оборот ≥ 1 млрд ISK, средняя в спреде 5–95 %. **Сбросить фильтры** снимает условия.

**«Дорогим товаром считать»** — порог для выгодности входа, по умолчанию 500 млн ISK.

### Market export logs

`.txt` экспорта стакана из EVE: имя, маржа и прибыль с вашими комиссиями.

Локальный запуск: путь к папке в **Настройки → Основные → Market logs**, новые файлы подхватываются сами. На [веб-версии](https://wafphlez.github.io/ExcelOnline-Market/) — перетащите `.txt` или **«Выбрать .txt»**.

### Персонаж

Вход через EVE SSO. Чтение кошелька и сделок, имущества и активных ордеров.

Сводка: net worth, кошелёк, активы, эскроу buy-ордеров, PLEX. Период: **1 день**, **Неделя**, **Месяц**, **3 мес**, **Вся выгрузка**.

Прибыль по типам: **Купля–продажа** или **Все типы**; **FIFO** или **Брутто**.

**Активные Market Orders** сравниваются с открытой книгой того же региона.

### Настройки

- **Broker fee** и **Sales tax** — по умолчанию 1,4 % и 4,2 %. От них считается маржа.
- Удаление выгрузок. Путь к market logs — в локальном режиме разработки.
- Тема: Caldari, Gallente, Minmatar, Amarr. **Скрыть UI** / **Показать UI**, облако, warp, звёзды.

## Локальный запуск

[Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev
```

Обычно `http://localhost:5173`.

Вход персонажа: приложение на [developers.eveonline.com](https://developers.eveonline.com/), в Callback URL — тот же адрес, которым открываете сайт (`localhost` и `127.0.0.1` различаются, слэш в конце тоже). Скопируйте `.env.example` в `.env`, укажите `VITE_EVE_SSO_CLIENT_ID`, перезапустите `npm run dev`. `VITE_EVE_SSO_REDIRECT_URI` — только если callback отличается от адреса страницы.

Перед первой выгрузкой ESI:

```bash
npm run prefetch:esi-universe
```

Docker, тот же `.env`:

```bash
docker compose up --build app-dev
```

`http://localhost`. Остановка: `docker compose down`.

Сборка для просмотра: `docker compose --profile preview up --build app-preview` — тоже `http://localhost`, папка market logs с диска недоступна.

| Команда | Зачем |
|---|---|
| `npm run dev` | Локальный запуск |
| `npm run build` | Сборка в `dist` |
| `npm run preview` | Просмотр сборки |
| `npm test` | Тесты |
| `npm run prefetch:esi-universe` | Каталог предметов ESI |
