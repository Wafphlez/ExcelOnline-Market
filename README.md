# Excel Online Market

Веб-версия: [https://wafphlez.github.io/ExcelOnline-Market/](https://wafphlez.github.io/ExcelOnline-Market/). Устанавливать ничего не нужно — откройте ссылку в браузере.

Таблица для торговли в EVE Online. Загружаете выгрузку рынка или собираете её сами, смотрите маржу с учётом своих комиссий, отсекаете слабые позиции фильтрами и сравниваете два региона. Отдельная вкладка показывает кошелёк, сделки и ордера вашего персонажа.

Excel разбирается прямо в браузере. Наружу уходят только действия, которые вы запускаете сами: выгрузка с официального ESI, вход через EVE SSO и ссылки на EVE Tycoon. Готовые книги остаются в этом браузере и открываются снова после перезагрузки. Файл с тем же именем заменяет предыдущий.

## Руководство

В шапке две вкладки: **Торговля** и **Персонаж**.

### Откуда берётся таблица

На вкладке **Торговля** слева два источника.

**Новая выгрузка ESI** собирает книгу по региону с официального рынка EVE.

1. Выберите регион: The Forge (Jita), Domain (Amarr), Heimatar (Rens), Sinq Laison (Dodixie) или Metropolis (Hek).
2. Выберите окно истории: **30**, **7** или **2** дня. От него зависят сделки за сутки и оборот.
3. При необходимости включите **«Выгрузить актуальные ордера»** — в файл попадёт снимок лучших цен.
4. **«Выгрузить только торговый хаб»** оставляет ордера главной станции региона (Jita, Amarr, Rens, Dodixie или Hek).
5. Нажмите **«Сформировать (ESI)»**.

Полная выгрузка обычно занимает несколько минут: читаются все страницы ордеров, без ручного лимита. Прогресс виден на панели. **«Стоп → xlsx»** обрывает сбор и сохраняет уже накопленное. **«Стоп → принудительно»** прерывает сбор без файла. Готовый `.xlsx` скачивается и сразу открывается в таблице.

**Локальный Excel** — свой файл `.xlsx` или `.xls`: перетащите его в зону или выберите с диска. Подходит и сторонняя выгрузка в том же формате колонок.

### Один регион и перевозка между регионами

Блок **Торговля** работает с уже сохранёнными книгами.

- **В одном регионе** — выберите файл и нажмите **«Открыть»**. Кнопки рядом обновляют список и удаляют выбранный файл.
- **Между регионами** — **Регион 1** это рынок, откуда везёте товар, **Регион 2** — куда продаёте. Оба файла берутся из сохранённых выгрузок. Стрелка меняет их местами, **«Применить сравнение»** строит таблицу по совпавшим предметам.

В сравнении цена покупки — sell региона 1, цена продажи — sell региона 2. Объём сделок, оборот и средняя цена берутся с рынка продажи. Маржа считается уже с вашими комиссиями.

Весь список выгрузок можно стереть в настройках: **Настройки → Основные → Выгрузки → Удалить выгрузки** (кнопку нужно нажать дважды). Там же виден размер кеша.

### Как читать таблицу

Колонки можно сортировать. Под заголовком — фильтр по диапазону или по тексту типа предмета. Наведите курсор на заголовок, чтобы увидеть подсказку.

| Колонка | Что показывает |
|---|---|
| Название | Клик копирует имя. Иконка рынка открывает карточку на EVE Tycoon, если в строке есть type id. |
| Тип предмета | Категория из выгрузки. Клик подставляет значение в фильтр. |
| Сделок за сутки | Сколько штук прошло за выбранное окно истории. |
| Оборот за сутки | Оборот в ISK. |
| Объём перевозки | Сколько м³ занимает одна штука в трюме. У кораблей это packaged volume. |
| Средняя цена, Sell, Buy | Средняя цена, самый дешёвый ордер на продажу и самый дорогой ордер на покупку. |
| Маржа | Прибыль после broker fee и sales tax. Фон ячейки тем сильнее, чем выше маржа. |
| Средняя в спреде | Где средняя цена лежит между buy и sell: 0 % у покупки, 100 % у продажи. Под шкалой — условное разбиение сделок по сторонам. |
| Спред | Разница sell − buy в ISK за штуку. |
| Выгодность входа | Оценка 0–100 %: маржа, ликвидность и ширина спреда. У дорогого товара вклад маржи слабее. Нет сделок или оборота — оценка занижается. |

Над таблицей — **быстрые фильтры**. Каждый добавляет одно условие, **«Применить все»** включает набор целиком, **«Сбросить фильтры»** снимает все.

Базовый набор:

- сделок за сутки не меньше 20;
- маржа не меньше 5 %;
- оборот не меньше 1 млрд ISK;
- средняя цена в спреде между 5 % и 95 % (не прижата к buy и не прижата к sell).

Рядом поле **«Дорогим товаром считать»**. По умолчанию порог 500 млн ISK. Выше него выгодность входа меньше опирается на маржу. Колёсико мыши над числовым полем меняет значение мелким шагом.

Фильтры, комиссии и порог запоминаются в этом браузере.

### Логи экспорта рынка

Блок **Market export logs** читает `.txt`, которые EVE пишет при экспорте стакана. Для предмета показываются имя (со ссылкой на EVE Tycoon), маржа и прибыль в ISK с вашими комиссиями. Переключатель в заголовке блока выключает разбор.

Если приложение запущено у вас на компьютере (`npm run dev` или Docker), укажите папку логов в **Настройки → Основные → Market logs**, например `Documents\EVE\logs\Marketlogs`. Новые файлы подхватываются сами.

На опубликованной странице браузер папку на диске не видит: перетащите `.txt` в блок или нажмите **«Выбрать .txt»**.

### Персонаж

Вкладка **Персонаж** входит через EVE SSO. Приложение просит только чтение:

- кошелёк, журнал и рыночные сделки;
- список имущества — для оценки капитала;
- активные buy- и sell-ордера.

На экране входа CCP будет тот же список. Принять нужно весь набор.

После входа видны портрет, корпорация и сводка: оценка net worth, кошелёк, оценка активов, ISK в эскроу buy-ордеров и оценка PLEX в имуществе. Период анализа: **1 день**, **Неделя**, **Месяц**, **3 мес**, **Вся выгрузка**.

График и таблица **«Торговая прибыль по типам»**:

- **Купля–продажа** — предметы, которые и покупали, и продавали; **Все типы** — все рыночные движения.
- **FIFO** сопоставляет продажи с более ранними покупками; **Брутто** показывает оборот без такого сопоставления.

Ниже — **Активные Market Orders**: ваши ордера на продажу и покупку. Если открыта книга того же региона, строка сравнивается с ней.

Кнопка обновления запрашивает данные заново. **Выйти** завершает сессию в этом браузере.

Чтобы вход заработал, при локальном запуске нужен Client ID — см. следующий раздел.

### Настройки

Шестерёнка справа в шапке.

**Основные**

- **Broker fee** и **Sales tax** — ваши проценты из игры. От них считается маржа в таблице и в логах. По умолчанию 1,4 % и 4,2 %.
- Путь к папке market logs — только когда приложение запущено локально в режиме разработки.
- Удаление сохранённых выгрузок.

**Интерфейс**

- **Скрыть UI** оставляет фон; вернуть экран — кнопка **«Показать UI»**.
- Облако внизу, warp и звёзды.
- Тема: Caldari, Gallente, Minmatar, Amarr.

Левую панель на широком экране можно сделать уже или шире: потяните разделитель между панелью и таблицей.

## Локальный запуск

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который напишет Vite. Обычно это `http://localhost:5173`.

### Вход персонажа

1. Создайте приложение на [developers.eveonline.com](https://developers.eveonline.com/).
2. В Callback URL укажите тот адрес, которым открываете сайт. `http://localhost:5173` и `http://127.0.0.1:5173` для CCP — разные значения. Лишний слэш в конце тоже меняет адрес.
3. Скопируйте `.env.example` в `.env` и впишите Client ID:

```bash
cp .env.example .env
```

В PowerShell:

```powershell
Copy-Item .env.example .env
```

```
VITE_EVE_SSO_CLIENT_ID=ваш_client_id
```

`VITE_EVE_SSO_REDIRECT_URI` заполняйте только если callback должен отличаться от адреса страницы. После правки `.env` перезапустите `npm run dev`.

### Каталог предметов для выгрузки ESI

Названия и группы предметов берутся из файла в проекте. Перед первой выгрузкой его стоит обновить:

```bash
npm run prefetch:esi-universe
```

### Docker

Тот же `.env`, затем:

```bash
docker compose up --build app-dev
```

Сайт откроется на `http://localhost`. Остановка: `docker compose down`.

Сборка как для публикации:

```bash
docker compose --profile preview up --build app-preview
```

Тоже `http://localhost`. В этом режиме папка market logs с диска недоступна: логи открываются перетаскиванием `.txt`.

### Команды

| Команда | Зачем |
|---|---|
| `npm run dev` | Запуск для работы на своём компьютере |
| `npm run build` | Сборка сайта в папку `dist` |
| `npm run preview` | Просмотр собранного сайта |
| `npm test` | Проверка расчётов |
| `npm run prefetch:esi-universe` | Обновить локальный каталог предметов ESI |
